Signal

A recording is
only the start.

Sampled at

16 kHz Enough for every measure on this page and for the speech band that carries them. The rate is pinned rather than negotiated: the FFT axis, the WAV header and every duration in the app assume it.
01

Captured off the main thread.

Recording runs in an audio worklet, so drawing a waveform can never cost you a block of audio. It used to.

02

Measured on the spot.

F0, harmonics-to-noise, jitter and shimmer are extracted the moment a take is saved. Not that evening, not next week.

03

Checked before it counts.

Level, clipping and duration are reported against the task's own thresholds, so a take that will not survive analysis is caught immediately.

The essentials.

Capture

A matched pairof microphones.

Two matched MEMS elements, recording in stereo at 16 kHz.

Protocol

The task decides,not the clinician.

Sustained vowel, pa-ta-ka, CAPE-V sentences and the Rainbow passage, each with its own duration and prompt.

Connect

USB-C, Wi-Fi,or no device at all.

The same capture path serves all three, including the computer's own microphone, so the software can be tried before the hardware arrives.

Design

Built to be
forgotten.

The best thing a recorder can do during a consultation is disappear. One continuous shell, one control, and a screen that answers the only question worth asking mid-take: is it still running?
