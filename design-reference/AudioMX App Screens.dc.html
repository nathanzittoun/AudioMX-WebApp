Rules
No rounded cards. Panels are white rectangles separated by 1px hairlines — the current build's 16px radii and drop-shadows are what make it read as a template.
One accent. #2f5d8f for the active/selected state only. Green, amber and red are reserved for device and signal state, never decoration.
Every number is mono. dBFS, Hz, %, timers, IDs. Prose is never mono.
Status is a sentence. Each input prints why it is unavailable, as text, next to itself.
Emoji removed. The 🏥 / 🔊 / 🫁 icons are replaced by mono labels — except the patient screen, where a large task glyph genuinely helps.

Patient screen states
Get ready — amber bar, “Get ready…”, task title dimmed, no timer.
Countdown — the number fills the screen (240px, mono), bar amber.
Speak now — green bar + green top rule, as shown; timer counts down.
Reading tasks — CAPE-V lines / Rainbow passage replace the step list at 40px, 1.5 line-height, max 22 words per line.
Done — bar goes neutral, “Thank you — one moment”, no metrics ever shown to the patient.
